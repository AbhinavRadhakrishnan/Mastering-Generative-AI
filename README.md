# 🚀 Mastering Generative AI

Welcome to **Mastering Generative AI** — a comprehensive, hands-on repository designed to build a strong foundation in **Generative AI**, **Large Language Models (LLMs)**, and **real-world GenAI systems**.

This repository follows a **step-by-step learning approach**, progressing from core concepts to advanced GenAI applications.

---

## 📌 About This Repository

The goal of this repository is to:
- Understand how modern Generative AI systems work
- Learn LLM fundamentals from scratch
- Build practical GenAI applications
- Explore RAG, agents, and deployment strategies
- Create a solid GenAI portfolio for real-world use

This repo is suitable for **students, ML engineers, and aspiring GenAI engineers**.

---

## 🧠 Topics Covered

- Introduction to Generative AI
- Large Language Models (LLMs)
- Transformers & Attention Mechanism
- Prompt Engineering
- Tokenization & Embeddings
- Retrieval-Augmented Generation (RAG)
- Vector Databases
- AI Agents & Tool Calling
- Model Inference & Optimization
- Deployment & Production Basics
